# Nakul Gupta — Personal Portfolio

## About the Project

This is my personal developer portfolio, built as part of my journey as a Computer Science and Engineering student at JK Lakshmipat University, Jaipur.

The website presents my technical skills, projects, education, certifications, research experience, and resume. It also includes a contact form through which visitors can send messages.

## Run the Project Locally

### Prerequisites

Make sure Node.js and npm are installed on your computer.

### 1. Clone the repository

```bash
git clone 
cd Nakul_Gupta_Portfolio
```


### 2. Set up the backend

Open a terminal and run:

```bash
cd server
npm install
```

Create a `.env` file inside the `server` folder using the provided `.env.example` as a reference. Add your own MongoDB connection string and the required environment variables.

Start the backend using the script available in `server/package.json`. If the project uses `dev`, run:

```bash
npm run dev
```

### 3. Set up the frontend

Open a second terminal and run:

```bash
cd client
npm install
npm run dev
```

### 4. Open the website

Open the local URL shown in the terminal, usually:

`http://localhost:5173`

Make sure the backend is also running for features that require the API or database connection.
